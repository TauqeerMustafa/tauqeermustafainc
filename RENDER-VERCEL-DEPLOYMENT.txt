PART 2: DEPLOY FRONTEND TO VERCEL (3 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 2.1: Login to Vercel
────────────────────────────────────────────────────────────────

1. Go to: https://vercel.com/login
2. Sign in with GitHub

Step 2.2: Import Project (If Not Already Deployed)
────────────────────────────────────────────────────────────────

If frontend is NOT on Vercel yet:

1. Click "Add New..." → "Project"
2. Import: tauqeermustafainc repository
3. Framework: Next.js (auto-detected)
4. Root Directory: frontend
5. Click "Deploy"
6. Wait 2-3 minutes

If frontend IS already on Vercel:

1. Go to: https://vercel.com/dashboard
2. Find your project
3. Click on it
4. Continue to Step 2.3

Step 2.3: Add Environment Variables
────────────────────────────────────────────────────────────────

1. In your Vercel project
2. Click "Settings" tab
3. Click "Environment Variables" (left sidebar)
4. Add these variables:

   Variable 1:
   ┌─────────────────────────────────────────────────────┐
   │ Key: WA_SERVICE_URL                                 │
   │ Value: https://tmi-whatsapp-service.onrender.com   │
   │ Environment: Production ☑  Preview ☑  Development ☑│
   └─────────────────────────────────────────────────────┘

   Variable 2:
   ┌─────────────────────────────────────────────────────┐
   │ Key: WEBHOOK_VERIFY_TOKEN                           │
   │ Value: tmi_webhook_2026                             │
   │ Environment: Production ☑  Preview ☑  Development ☑│
   └─────────────────────────────────────────────────────┘

5. Click "Save"

Step 2.4: Redeploy
────────────────────────────────────────────────────────────────

1. Go to "Deployments" tab
2. Click "..." on latest deployment
3. Click "Redeploy"
4. Check "Use existing Build Cache"
5. Click "Redeploy"
6. Wait 1-2 minutes

✅ Your frontend will auto-deploy with new environment variables

Issue: Can't send messages
────────────────────────────────────────────────────────────────
1. Check WA service health endpoint
2. Verify WA_SERVICE_URL in Vercel environment variables
3. Make sure it's: https://tmi-whatsapp-service.onrender.com
   (no trailing slash!)
4. Check Render logs: Dashboard → Service → Logs

Issue: Messages not appearing in inbox
────────────────────────────────────────────────────────────────
1. Open browser console (F12)
2. Look for errors in Console tab
3. Check Network tab for failed API calls
4. Verify both services are running (green "Live" status)

Issue: Webhook not receiving messages
────────────────────────────────────────────────────────────────
1. Check Meta webhook configuration
2. Verify URL: https://tmi-whatsapp-service.onrender.com/webhook
3. Verify token: tmi_webhook_2026
4. Check Render logs for webhook POST requests
5. In Render logs, you should see: "📨 Message from..."

Issue: CORS errors
────────────────────────────────────────────────────────────────
1. CORS is already configured in webhook.js
2. If still having issues, check browser console
3. Verify Vercel domain is allowed
4. Restart Render service if needed

Issue: Render service spinning down (Free tier)
────────────────────────────────────────────────────────────────
Free tier spins down after 15 minutes of inactivity.
First request after spin-down takes ~30 seconds.

Solutions:
1. Upgrade to paid tier ($7/month)
2. Use uptime monitor (UptimeRobot) to ping every 10 minutes
3. Accept the cold start delay
