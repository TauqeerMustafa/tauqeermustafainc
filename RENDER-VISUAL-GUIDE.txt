Step 1.1: Create New Web Service
────────────────────────────────────────────────────────────────

After logging in:

1. You'll see Render Dashboard
2. Click blue "New +" button (top right)
3. Select "Web Service" from dropdown

Step 1.2: Connect GitHub Repository
────────────────────────────────────────────────────────────────

You'll see "Create a new Web Service" page:

1. If first time: Click "Connect GitHub"
   → Authorize Render to access your GitHub

2. You'll see list of your repositories
3. Find: "whatsapp-webhook"
4. Click "Connect" button next to it

Step 1.5: Create Service
────────────────────────────────────────────────────────────────

1. Scroll to bottom
2. Click blue "Create Web Service" button
3. Wait 2-3 minutes (you'll see build logs)
4. When done, you'll see: "Live" with green dot
5. Copy your service URL (top of page)
   Example: https://tmi-whatsapp-service.onrender.com

PART 2: UPDATE FRONTEND SERVICE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 2.1: Find Your Frontend Service
────────────────────────────────────────────────────────────────

1. Go back to Render Dashboard
2. Click "Dashboard" in top left menu
3. You'll see list of your services
4. Find your frontend service (tauqeermustafainc or similar)
5. Click on it

Step 2.2: Add Environment Variables
────────────────────────────────────────────────────────────────

1. In left sidebar, click "Environment"
2. You'll see existing environment variables
3. Click "Add Environment Variable" button
4. Add FIRST variable:
   Key: WA_SERVICE_URL
   Value: https://tmi-whatsapp-service.onrender.com
   (use YOUR actual WA service URL from Step 1.5)

5. Click "Add Environment Variable" again
6. Add SECOND variable:
   Key: WEBHOOK_VERIFY_TOKEN
   Value: tmi_webhook_2026

7. Click "Save Changes" button (bottom)
8. Service will auto-redeploy (2-3 minutes)
9. Wait for "Live" status with green dot

✅ Frontend Updated!

Step 3.1: Go to Meta Business Manager
────────────────────────────────────────────────────────────────

1. Open new tab
2. Go to: https://business.facebook.com
3. Login with your Facebook account
4. Select your business

Step 3.2: Navigate to WhatsApp Settings
────────────────────────────────────────────────────────────────

1. In left sidebar, click "WhatsApp Accounts"
2. Click your WhatsApp Business Account
3. Click "WhatsApp Manager" button
4. In left menu, click "Configuration"

Step 3.3: Configure Webhook
────────────────────────────────────────────────────────────────

Scroll down to "Webhook" section:

1. Click "Edit" button
2. You'll see webhook configuration form:

   ┌─────────────────────────────────────────────────────┐
   │ Callback URL                                        │
   │ ┌─────────────────────────────────────────────────┐│
   │ │ https://tmi-whatsapp-service.onrender.com/      ││
   │ │ webhook                                         ││
   │ └─────────────────────────────────────────────────┘│
   │                                                     │
   │ Verify Token                                        │
   │ ┌─────────────────────────────────────────────────┐│
   │ │ tmi_webhook_2026                                ││
   │ └─────────────────────────────────────────────────┘│
   └─────────────────────────────────────────────────────┘

3. Enter YOUR actual WA service URL + /webhook
   Example: https://tmi-whatsapp-service.onrender.com/webhook

4. Enter verify token: tmi_webhook_2026

5. Click "Verify and Save" button

6. If successful, you'll see ✅ "Webhook verified"

Step 3.4: Subscribe to Webhook Fields
────────────────────────────────────────────────────────────────

Still in Webhook section:

1. Look for "Webhook fields" or "Subscribe to fields"
2. Check these boxes:
   ☑ messages
   ☑ message_status

3. Click "Save" or "Subscribe"

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: Can't send messages
─────────────────────────────────────────────────────────────────
1. Check WA service health endpoint
2. Verify WA_SERVICE_URL in frontend environment
3. Check Render logs: Dashboard → WA Service → Logs

Issue: Messages not appearing in inbox
─────────────────────────────────────────────────────────────────
1. Open browser console (F12)
2. Look for errors
3. Verify both services are "Live"

Issue: Webhook not working
─────────────────────────────────────────────────────────────────
1. Check Meta webhook configuration
2. Verify URL matches: https://your-wa-service.onrender.com/webhook
3. Check token: tmi_webhook_2026
4. Look at WA service logs for incoming requests
