Send Text Message:
  POST /api/whatsapp/send
  {
    "type": "text",
    "to": "923001234567",
    "message": "Your message"
  }

Send Button Message:
  POST /api/whatsapp/send
  {
    "type": "buttons",
    "to": "923001234567",
    "bodyText": "Choose:",
    "buttons": [
      {"id": "opt_1", "title": "Option 1"}
    ]
  }

Get Messages:
  GET /api/whatsapp/messages

  • View all received/sent messages
  • Auto-refreshes every 5 seconds
  • Blue = Inbound, Green = Outbound

  1. Select message type (Text/Buttons/Template)
  2. Enter phone: 923001234567 (no + symbol!)
  3. Fill message details
  4. Click "Send Message"

Can't send messages?
  ✓ Check: http://localhost:3001/health
  ✓ Verify WA_SERVICE_URL in .env.local
  ✓ Phone format: 923001234567 (no +)

Messages not showing?
  ✓ Check both services are running
  ✓ Check browser console for errors
  ✓ Try manual page refresh

CORS errors?
  ✓ Restart WA service
  ✓ Clear browser cache
