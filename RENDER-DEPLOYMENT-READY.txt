🚀 DEPLOYMENT STEPS

Step 1: Deploy WA Service
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://dashboard.render.com
2. Click "New +" → "Web Service"
3. Connect repository: whatsapp-webhook
4. Configure:
   Name: tmi-whatsapp-service
   Branch: main
   Build Command: npm install
   Start Command: npm start

5. Add Environment Variables (copy from above):
   Click "Add Environment Variable" 5 times
   Paste each variable name and value

6. Click "Create Web Service"
7. Wait 2-3 minutes
8. Copy your URL: https://tmi-whatsapp-service.onrender.com

Step 2: Update Frontend on Render
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Render dashboard → Your frontend service
2. Click "Environment" tab
3. Add these two variables:

   WA_SERVICE_URL=https://tmi-whatsapp-service.onrender.com
   WEBHOOK_VERIFY_TOKEN=tmi_webhook_2026

4. Click "Save Changes"
5. Frontend will auto-redeploy (2-3 minutes)

Step 3: Configure Meta Webhook
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://business.facebook.com
2. WhatsApp → Configuration → Webhook
3. Click "Edit"
4. Enter:
   Callback URL: https://tmi-whatsapp-service.onrender.com/webhook
   Verify Token: tmi_webhook_2026

5. Click "Verify and Save"
6. Subscribe to: messages, message_status
